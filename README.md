# 🛒 AegisMart AI

## 基於 Multi-Agent 視覺感知的賣場「即時動態定價大腦」

> 大賽參賽企劃書 — 以「超市生鮮區晚間即期品」作為降維打擊的試金石，完美融合 55% 實用價值、20% 商業計畫、15% 技術實現與 10% 資訊安全的評分權重。

---

## 一、項目摘要 (Abstract)

傳統賣場長期面臨「即期品報廢率高、冷門區域人流死角、促銷靠排程而非即時供需」的結構性痛點。固定標價與定時促銷模式無法回應瞬息萬變的賣場人流，導致食品浪費、營收流失、顧客體驗僵化。

本項目推出 **AegisMart AI**，一套專為賣場營運方設計的 AI 即時動態定價副駕駛（Copilot）。系統採用 **LangGraph 多智能體（Multi-Agent）圖架構**，透過監視器 AI 視覺感知（人流密度 + 貨架互動行為），融合庫存即期狀態與時段規律，以「**視覺感知 ➡️ 策略推演 ➡️ 店長審批（Human-in-the-Loop）➡️ 電子看板即時更新**」的嚴謹流程落地。

我們以「**超市生鮮區晚間 8 點即期品促銷**」作為原型驗證（PoC），展示系統如何偵測到「生鮮區人流驟降 + 即期品剩餘 40%」後，自動推演出「限時 6 折 + 看板動態廣播 + 鄰近走道導引」的完整策略，店長一鍵核准後看板即時更新，將報廢率從 35% 降至 8%。本系統底層框架可無縫複製至便利商店、量販店、百貨專櫃等所有零售場景。

## 二、實用價值分析 (55%)：直擊行業痛點與創造爽點

### 1. 行業痛點（痛在哪）

- **即期品大量報廢**：生鮮、鮮食、烘焙品每日報廢率高達 30-40%，傳統「打烊前統一貼折扣」太被動，錯過黃金促銷時間窗口。
- **冷門區域人流死角**：賣場 20% 的走道貢獻不到 5% 營收，商品曝光率低導致滯銷，最終仍走向報廢或退貨。
- **促銷排程僵化**：傳統 DM/海報促銷週期為 7-14 天，無法回應「今天下午這個走道突然沒人」的即時狀況，人力調整成本高。

### 2. 系統創造的核心價值（爽點在哪）

- **報廢率暴降（省成本）**：AI 在「還來得及賣掉」的時間窗內精準啟動促銷，報廢率從 35% 降至 8%，年省數百萬食品浪費。
- **人流導引活化死角（多賺）**：冷門區看板即時跳出吸睛折扣，將熱區溢出人流引導至死角區，全場坪效均衡提升 20%。
- **即時反應零人力（省力）**：店長不需巡場盯庫存、手動貼標籤，系統自動推播方案到手機，一鍵核准看板秒更新。

## 三、技術實現與工具運用 (15%)：真正的 Agentic AI 展現

本作品利用 **LangGraph** 開發框架，結合 **Edge AI 視覺感知**，建構具備「自主觀察、策略推演、自我反思」能力的 Multi-Agent 閉環網絡：

```
              ┌──────────────────────────────────┐
              │ 1. 視覺人流感知 Agent            │
              │    (監視器 AI / 邊緣運算)        │
              │    人流密度 + 貨架互動行為       │
              └────────────────┬─────────────────┘
                               │
                               ▼
┌─────────────────────────┐ 協同對話 ┌─────────────────────────┐
│ 3. 營收反思與優化 Agent │◄────────►│ 2. 動態定價策略 Agent   │
│    (歷史回顧/行為洞察/  │          │    (折扣推演/看板內容/  │
│     商品組合建議)       │          │     人流導引策略)      │
└─────────────────────────┘          └─────────────────────────┘
                               │
                               ▼
                  ┌───────────────────────┐
                  │ 🧑‍💼 店長/樓管審批控制台  │
                  │    → 電子看板即時更新  │
                  └───────────────────────┘
```

### 1. 三大代理模組運行流程

#### 🔹 即時觀察：視覺人流感知 Agent (Visual Flow Sensing)

**Agent 代理行為**：透過賣場既有監視器 + Edge AI 模組（如 NVIDIA Jetson），即時輸出：
- 各區域人流密度（人/分鐘）
- 貨架互動行為（商品被拿起次數、放回率、平均停留秒數）
- 當人流密度低於閾值 + 即期品庫存 > 30% 時，自動觸發定價推演

#### 🔹 策略推演：動態定價策略 Agent (Dynamic Pricing Engine)

**Agent 代理行為**：基於場域狀態，推演多情境促銷方案：
- **情境 A**：生鮮區人流 -60% + 即期品 40% → 看板「限時 6 折」+ 鄰近走道導引文案
- **情境 B**：零食區停留久但放回率高 → 推演「買二送一」降低決策門檻
- **情境 C**：全場均衡但特定品項滯銷 → 「今日驚喜價」聚焦單品

將方案推播至店長手機，等待 **Human-in-the-Loop 審批**。

#### 🔹 反思優化：營收反思與優化 Agent (Revenue Reflection & Optimization)

**Agent 代理行為**：每日打烊後自動回顧當日所有促銷執行結果，進行自我反思（Reflection）：
- 「為何今天 6 折促銷只消化了 50% 即期品？」→ 發現啟動時間太晚（20:30 → 建議提前至 19:45）
- 分析貨架互動行為異常 → 「顧客拿起又放回率 70%」→ 建議調整陳列位置或價格帶
- 將最佳實踐存入 RAG 記憶庫，持續優化

### 2. 工具調用 (Tool Use)

| 端 | 工具 |
|----|------|
| 感知端 | Edge AI 攝影機模組、POS/ERP 即期庫存 API |
| 數據端 | SQL-Agent 查詢歷史銷售、報廢率、人流模式 |
| 執行端 | 審批後調用電子看板 API 更新內容、POS 系統同步折扣碼 |

## 五、資訊安全與風險防範 (10%)

賣場監視器涉及顧客隱私，本系統設計了四道硬性防線：

1. **影像零儲存零傳輸 (Zero Image Retention)**
   - 原始影像僅在 Edge AI 裝置本地處理
   - 僅輸出統計數據（人數、熱區座標、互動次數），原始畫面即時刪除
   - 任何時刻皆無法回溯還原個人影像

2. **邊緣運算隔離 (Edge Computing Isolation)**
   - AI 推論在 NVIDIA Jetson 等邊緣裝置完成
   - 統計數據以加密通道傳送至定價引擎，不經公網
   - 即使主機被入侵也取不到任何影像

3. **費率熔斷與權限控管 (Guardrails & RBAC)**
   - 折扣上限硬性寫死（不超過 50%）、不低於成本底線
   - Agent 無權自主更新看板，店長審批才執行
   - 異常折扣頻率自動凍結（防止 Agent 暴走）

4. **Prompt Injection 防禦**
   - Llama Guard 護欄攔截惡意輸入
   - 防止透過偽造庫存數據誘導 Agent 產出虧本促銷
